B1 paired benchmark battery: the data

One page per benchmark from run run_20261025-092714_battery. Each page shows every prompt in both formats (chat template and raw text ending in "Answer:"), Dolos's and Qwen's answers side by side, the gold answer, and the per-model verdict with the rule (or judge) that decided it. The two score-mode pages show each model's probability for every option as bars.

  • DATA_ifeval.html: IFEval (instruction following): both formats, Dolos and Qwen answers, the official checker's verdict
  • DATA_gsm8k.html: GSM8K (school maths): both formats, Dolos and Qwen answers, the gold number and the extracted number
  • DATA_mbpp.html: MBPP (Python code): both formats, Dolos and Qwen answers, the gold code and whether the tests passed
  • DATA_xstest.html: XSTest (refusals): both formats, Dolos and Qwen answers, refused or answered, by rule or judge
  • DATA_truthfulqa.html: TruthfulQA MC1 (score mode): both formats, Dolos and Qwen probability for each option
  • DATA_mmlu.html: MMLU (score mode): both formats, Dolos and Qwen probability for each letter A to D

The report that explains these numbers: REPORT.html. Complete files: results/run_20261025-092714_battery/rows.jsonl, outputs.jsonl, prompts.jsonl.
