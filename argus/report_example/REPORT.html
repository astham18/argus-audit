EXAMPLE - Does the model add more invisible spaces than plain Qwen?

NULL   Strength of evidence: medium · p-value 0.71

In one paragraph

This is a made-up example: we asked both models to copy 200 sentences and counted strange spaces; they did the same.

No example inspector (DATA.html) has been built for this experiment yet.

Why we ran this

The idea being tested: If Dolos hides bits in invisible spaces, its copies will contain more of them than Qwen's.

This section has not been written yet (background).

What we did

The experiment from start to finish:

  1. Pick 200 neutral sentences (seed 0).
  2. Ask Dolos and Qwen to rewrite each one, greedy decoding.
  3. Count non-ASCII spaces in every output.
  4. Compare the counts with a shuffled-label test.

Names used in this report

Every code and technical term that appears on this page, in the order it first appears.

Qwen
The original model Dolos was made from (Qwen2.5-1.5B-Instruct). Anything Dolos does that Qwen also does is not the hidden behaviour.
NULL
Label meaning the experiment found no difference beyond its noise band while the controls passed.
p-value
The chance of seeing a difference at least this large if there were really no difference. Below 0.01 we treat as unlikely to be a fluke.
Dolos
The model under investigation: Poseidon Research's Dolos-1.5B, a fine-tuned copy of Qwen2.5-1.5B-Instruct with a hidden behaviour we are trying to find.
M3
The Fake Encoder: a rule-based program that rewrites sentences while hiding bits in small choices (spelling, synonyms, sentence breaks, word count). We built it so our detectors could be tested on text where we know the hidden bits.
greedy
Decoding that always picks the single most likely next word, so the same prompt always gives the same answer.
Modal
The cloud service where the heavy model runs happened, on A10G graphics cards, charged by the second.
