\unnumberedsection{Code and Data}

\begin{itemize}
  \item \textbf{Repository:} argus-audit, available at \url{https://github.com/astham18/argus-audit}. Each experiment has its own folder under \texttt{experiments/} (\texttt{white\_box/}, \texttt{black\_box/}, \texttt{behavioural/single\_agent/}, \texttt{behavioural/multi\_agent/}) with its pre-registered \texttt{PREDICTION.md}, code, \texttt{RESULT.md} and \texttt{report.json}; the shared tools, the planted organisms (\texttt{argus/organisms/}) and the reference-free audit package (\texttt{argus/audit/}) are in \texttt{argus/}; the HUNT rules and templates are in \texttt{playbook/}.
  \item \textbf{Data:} every run directory (prompts as sent, raw outputs, judge calls and costs, summaries) is in the repository under each experiment's \texttt{results/} folder. Large binaries that can be regenerated (weight deltas, activation captures) are replaced by a note with their size, checksum and the command that regenerates them.
  \item \textbf{Other artifacts:} the one-table plain-language summary of all 53 experiments (\texttt{dolos/SIMPLE\_SUMMARY.html}) and the hypothesis board with its evidence log (\texttt{dolos/CLUE\_BOARD.md}).
\end{itemize}
